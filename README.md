## Propósito del repositorio

Este repositorio contiene la documentación técnica previa requerida para operar de forma segura, eficiente y profesional la maqueta de laboratorio de **Multiplexación por División de Longitud de Onda Densa (DWDM)** durante las sesiones presenciales. Sirve como manual de consulta rápida sobre fundamentos físicos y normativas ITU-T, inventario de equipos del rack, procedimientos de configuración/medición y esquemas de interconexión física y lógica.
